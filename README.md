# Advanced Thought Mapper 5.0

**Advanced Thought Mapper 5.0** is a web-based application designed to help users organize their thoughts, todos, and ideas into clusters. It provides a responsive and interactive interface for managing tasks, grouping related items, and analyzing patterns in your workflow. The application is personalized for the user and supports drag-and-drop functionality, productivity tracking, and history management.

---

## Features

### 1. **Thoughts and Todos Management**
   - Add new thoughts and todos using input fields.
   - Drag and drop items between different containers (thoughts, todos, clusters).
   - Edit text directly in the UI with `contenteditable` fields.
   - Mark todos as completed with checkboxes.

### 2. **Cluster Management**
   - Create clusters to group related thoughts and todos.
   - Sort items within clusters.
   - Clear all clusters with a confirmation dialog.

### 3. **Productivity Tracking**
   - Assign productivity levels to todos: **productive**, **neutral**, or **unproductive**.
   - Change the color of thoughts to visually categorize them.

### 4. **History and Suggestions**
   - View a history of your application states and revert to previous snapshots.
   - Get suggestions based on repeated patterns in your thoughts and todos.

### 5. **Drag-and-Drop Functionality**
   - Easily move items between thoughts, todos, and clusters using drag-and-drop.

### 6. **Local Storage Persistence**
   - Save your data to local storage for persistence across sessions.
   - Load previous states from the history.

### 7. **Responsive Design**
   - The application is fully responsive and works on both desktop and mobile devices.

### 8. **Pattern Recognition**
   - The app analyzes your thoughts and todos to suggest common patterns, helping you identify recurring tasks or ideas.

---

## How to Use

1. **Adding Thoughts and Todos**
   - Enter a new thought or todo in the respective input fields and click the "Add Thought" or "Add Todo" button.

2. **Creating Clusters**
   - Enter a name for a new cluster in the "New cluster" input field and click "Add Cluster."

3. **Drag-and-Drop**
   - Drag thoughts or todos into clusters or back to the main containers.

4. **Editing Items**
   - Click on the text of any thought or todo to edit it directly.

5. **Productivity Levels**
   - Click the "Change Productivity" button on a todo to cycle through productivity levels.

6. **Color Coding Thoughts**
   - Click the "Change Color" button on a thought to cycle through color options.

7. **History**
   - View your history and click on a snapshot to revert to that state.

8. **Suggestions**
   - View suggested patterns based on recurring thoughts or todos and apply them to create new clusters.
